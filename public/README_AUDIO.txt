HOW TO UPLOAD YOUR CUSTOM WEDDING MUSIC:
=======================================

1. Drag and drop your audio file (.mp3 file) into the 'public' folder of this project in the file explorer.
2. Rename your uploaded audio file to exactly one of the following names (case sensitive):
   - wedding.mp3
   - music.mp3
   - audio.mp3

That's it! The system will automatically detect and play your file when the "Open Invitation" button is clicked.

If you don't upload a custom file, the invitation will beautifully play the default instrumental background track.
